# MineGuard Blast Zone 🚧⛏️

MineGuard Blast Zone is an integrated mining safety and monitoring system designed to improve worker safety, hazard detection, and operational monitoring in mining environments.

This repository combines multiple modules including:

- Blast Zone Monitoring System
- PPE Detection System
- Frontend Interface for Monitoring Dashboard

---

# 📂 Project Structure

```bash
MinGuard-Blast-Zone-main/
│
├── mineguard_PPE_detect/        # PPE Detection Module
├── mineguard-frontend-main/     # Frontend Dashboard/UI
├── static/                      # Static assets
├── templates/                   # HTML templates
├── app.py                       # Main backend application
├── requirements.txt             # Python dependencies
├── README.md                    # Project documentation
```

# 📸 PPE Detection Module

- Helmets
- Safety Vests

It uses computer vision and deep learning techniques for real-time detection.
